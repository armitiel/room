# Integracja Unreal
Tutaj utwórz rzeczywisty projekt Room w edytorze Unreal.
1. Ustal wersję silnika zgodną z hostingiem i frontendem Pixel Streaming.
2. Utwórz pusty projekt i włącz zgodną wtyczkę Pixel Streaming.
3. Zaimportuj eksport Blender; porównaj jednostki, materiały i kierunki osi.
4. Dodaj kolizje, kamerę i sterowanie oraz obsługę identyfikatorów wariantów.
5. Zbuduj aplikację na system docelowego serwera GPU.
6. Sprawdź lokalny spacer, a następnie sesję przez internet.
Nie dodano pozornego .uproject: projekt wymaga inicjalizacji i weryfikacji w zainstalowanym silniku.
Duże pliki Content przechowuj w Git LFS lub magazynie artefaktów po ustaleniu zasad.
